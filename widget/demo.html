Page de démonstration

Cette page simule un site Zend/PHP. Le widget Clara est chargé via un simple <script> et appelle le backend sur la même origine (/api/chat).

Servez cette page depuis le backend : uvicorn backend.main:app --port 8000 puis ouvrez http://localhost:8000/widget/demo.html.
